## Toolbox 
I love working with **R** for quick and efficient data dissection and analysis, such as facet_plot visualisation, correlation and colinearity analysis, data cleaning wth janitor and dplyr, and basic feature engineering. When it comes to Gen AI, ML and training complex models, I typically turn to **Python** with its extensive ML libraries and API support for working with Cloud services for MLOps. For presenting, I love using **Streamlit**, **R Shiny**, or **shadcn** with next.js.
